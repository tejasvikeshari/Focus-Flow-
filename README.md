# FocusFlow 🚀

FocusFlow is an AI-powered student productivity app designed to help students organize their studies, improve focus, and learn efficiently.

## ✨ Features

- 🤖 AI Study Assistant powered by Groq
- 🎯 Focus timer for productive study sessions
- ▶️ YouTube educational video search
- ⭐ Earn stars by completing focus sessions
- 🪐 Unlock planets as you earn focus points
- 💰 Expense tracking
- 📚 Student productivity tools

## 🛠️ Technologies Used

- React
- Vite
- Node.js
- Express
- Groq API
- YouTube Data API v3

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/tejasvikeshari/Focus-Flow-.git
   ```

2. Open the project folder:

   ```bash
   cd Focus-Flow-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project root.

5. Add your API keys:

   ```env
   GROQ_API_KEY=your_groq_api_key
   YOUTUBE_API_KEY=your_youtube_api_key
   ```

6. Start the application using the scripts configured in `package.json`.

## 🔐 Security

- Never commit your `.env` file.
- Never share your API keys publicly.
- Keep `.env` in `.gitignore`.
